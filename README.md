# Service Business Website Template

Demo: LuxeGlow Beauty & Spa.

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Before client delivery
Replace the demo business name, copy, photos, services, phone, location, hours, testimonials, and WhatsApp link.
